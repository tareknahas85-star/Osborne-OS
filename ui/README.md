# Osborne UI

Desktop shell and apps for Osborne OS (GTK3 + Openbox, light and dark themes).

Update a running system from GitHub:

    curl -fsSL https://raw.githubusercontent.com/tareknahas85-star/Osborne-OS/main/ui/update.sh | sudo bash

Then log out and back in. Needs internet and sudo. `ui/install.sh` can also be run from a local clone.

Shortcuts: Super+Space apps, Super+L lock, Super+M system monitor, Print / Shift+Print / Alt+Print screenshots.
