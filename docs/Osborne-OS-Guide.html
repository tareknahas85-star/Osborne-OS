Osborne OS
كمبيوترك كلو بكرت SD بجيبتك

أوبونتو حقيقي متنصّب عكرت SD حجمو 128 جيجا. بتحط الكرت بأي كمبيوتر تقريباً، بيقلع بنظامك إنت، ببرامجك وملفاتك، وملفاتك بقسم مقفول ما حدا بيفتحو بلا كلمة السر.

يلا نبنيشوف تقسيم الكرت
ليش "Osborne"؟
سنة 1981 طلع Osborne 1، أول كمبيوتر محمول نجح بالسوق. وزنو حوالي 11 كيلو، شاشتو 5 إنش، وكانو يحملوه متل الشنطة. حلمو كان «كمبيوترك معك وين ما رحت». نحنا كمّلنا نفس الحلم: كمبيوترك كلو صار وزنو غرامين وبيفوت بجيبتك.

🧩 شو هو بالضبط؟

مو نسخة تجريبية (Live)، هو نظام متنصّب كامل عالكرت.

🐧
أوبونتو حقيقي

Ubuntu Server 26.04 LTS متنصّب كامل، مو Live ولا persistence. كل شي بتنصّبو بيضل.

🔌
بيقلع عأي جهاز

إقلاع هجين BIOS + UEFI، يعني عالأجهزة القديمة والجديدة بلا ما تغيّر إعدادات الجهاز.

🪶
خفيف

واجهة Openbox مع شريط tint2 بس، وما في برامج زيادة. إنت بتنصّب اللي بدك ياه.

🔐
ملفاتك مقفولة

قسم الداتا مشفّر بـLUKS، وبيطلب كلمة السر وقت الإقلاع.

💾
بيحمي الكرت

zram بدل الـswap، وnoatime، وfstrim، مشان يقلّ الكتابة والكرت يعيش أطول.

📦
3 ملفات بس

دليل البناء، وسكربت الإعداد، وملف autoinstall جاهز اختياري.

🗂️ تقسيم الكرت

الكرت مقسوم لـ4 أقسام. دوس على أي قسم لتعرف ليش موجود.

💡 ليش النظام مو مشفّر؟ هيك بيقلع بسرعة وإذا صار عطل بتصلّحو بسهولة. اللي بدو حماية فعلاً هو شغلك، لأنك رح تحط الكرت بأجهزة غريبة.

🧰 شو بدك قبل ما تبلّش

علّم كل شي جهّزتو، وبينحفظ عهالجهاز.

    ⚠️ أهم شي: اختار القرص الصح

    التقسيم بيمسح القرص اللي بتختارو. إذا غلطت بالقرص، بتمسح قرص الكمبيوتر نفسو. دايماً تأكد بـlsblk وبالحجم.

    تمرين: هاد ناتج lsblk على جهاز فيه قرص داخلي وكرت الـSD بقارئ USB. أي واحد هو الكرت؟

    NAMESIZETYPETRAN
    nvme0n1476.9Gdisknvme
    sda119.1Gdiskusb
    sdb7.5Gdiskusb

    🔀 يدوي ولّا آلي؟

    🖐️
    يدوي (منصوح أول مرة)

    بتختار Custom storage layout بالمنصّب وبتعمل الأقسام الأربعة بإيدك. أسهل وأوضح لأول مرة.

    🤖
    Autoinstall آلي

    ملف autoinstall-user-data.yaml بيعمل كلشي لحالو، منيح إذا بدك تكرر العملية.

    ⚠️ قبل الآلي: عدّل سطر القرص بالملف (path: /dev/sda) ليطابق كرتك، وحط هاش كلمة سر المستخدم وكلمة سر الداتا المؤقتة، وجرّبو على جهاز وهمي (VM) أول. كلمة سر الداتا مكتوبة بالملف كنص، فغيّرها بعد أول إقلاع وامسح الملف من أي مكان مو آمن.
    توليد هاش كلمة سر المستخدم:
    mkpasswd --method=SHA-512 --rounds=4096

    🖥️ سطح المكتب

    بعد سكربت الإعداد، بيصير عندك سطح مكتب خفيف وكل أداة إلها شغلة وحدة.

    الأداةشو بتعمل
    Openboxمدير النوافذ، خفيف كتير
    tint2الشريط تحت: النوافذ المفتوحة والساعة
    rofiقائمة البرامج، بتفتحها بـSuper + D
    pcmanfmمدير الملفات وخلفية سطح المكتب
    lxterminalالتيرمينال
    nm-appletالواي فاي والإنترنت من الشريط
    lightdmشاشة تسجيل الدخول
    تنصيب أي برنامج بدك ياه:
    sudo apt install <package-name>

    🔐 ملفاتك المشفّرة (كل يوم)

    قسم الداتا بيتفك لحالو وقت الإقلاع. رح تطلعلك شاشة سودا بتطلب كلمة السر قبل شاشة الدخول، وهاد طبيعي ومقصود.

    📁
    وين ملفاتك؟

    بـ/mnt/data، والسكربت بيعملّك اختصار إلها اسمو ~/Work.

    🔄
    تغيير كلمة السر

    بأي وقت، بأمر واحد (تحت).

    ⛔
    إذا نسيتها

    ما في طريقة ترجّع الداتا أبداً. احفظها بمكان أمين.

    sudo cryptsetup luksChangeKey /dev/sdX4

    بدّل sdX باسم قرص الكرت عندك، و4 هو رقم قسم الداتا.

    💾 عمر الكرت والسرعة

    🏎️
    كرت سريع

    UHS-I عالأقل، والأحسن UHS-II إذا القارئ بيدعمها. الكتابة البطيئة بتخنق النظام كلو.

    🧠
    zram

    الـswap بالذاكرة بدل الكرت. السكربت بيفعّلو لحالو.

    📝
    noatime

    بيوقّف كتابة «آخر مرة انفتح الملف» مع كل قراءة.

    🧹
    fstrim

    تنظيف دوري للكرت إذا القارئ بيدعم TRIM، وما بيضر إذا ما بيدعم.

    🔌
    قارئ USB ثابت

    استعمل نفس القارئ الخارجي دايماً، مو قارئ الـSD الداخلي باللابتوب.

    ✅ قائمة الاختبار

    قبل ما تعتمد عالكرت بشغلك الحقيقي، جرّب هدول وعلّم اللي زبط.
